# Отчёт по лабораторной работе №2

Ким Максим Сергеевич, группа 221341, вариант 7.

## Средняя сложность

- **№7 Подсчёт гласных** — `lab2/vowels.py`: строка приводится к
  нижнему регистру, каждый символ проверяется на принадлежность
  строке гласных (русские и латинские буквы).
- **№9 Минимальный элемент списка** — `lab2/minimum.py`: обход
  списка сравнением текущего минимума со следующим элементом;
  пустой список вызывает `ValueError`.
- **№3 Факториал числа** — `lab2/factorial.py`: итеративное
  умножение от 1 до `n`; отрицательные значения отклоняются.

## Повышенная сложность

- **№7 Частота слов в файле** — `lab2/wordfreq.py`: файл читается
  построчно, слова очищаются от пунктуации через `str.strip` и
  приводятся к нижнему регистру, частоты хранятся в словаре.
- **№5 Игра «Угадай число»** — `lab2/guess_number.py`: цикл на
  `for` с ограниченным числом попыток, `random.randint` загадывает
  число, ввод/вывод вынесен в параметры `reader`/`writer`, поэтому
  игра тестируется без консоли.

## Проверка

- Демонстрация: `python -m lab2`.
- Тесты: `python -m unittest discover -s tests -v`.
- Стиль: `flake8 lab2 tests` (max-line-length = 79).
- CI: GitHub Actions workflow `.github/workflows/python-checks.yml`.
